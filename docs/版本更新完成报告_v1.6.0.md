### 3. 版本号管理最佳实践
- 用于修复的更新: `patch` (e.g., 1.6.0 → 1.6.1)
- 用于新功能的更新: `minor` (e.g., 1.6.0 → 1.7.0)
- 用于重大更改的更新: `major` (e.g., 1.6.0 → 2.0.0)

### 4. 版本发布流程
```bash
# 1. 更新版本号
node scripts/update-version.js 1.6.0

# 2. 提交修改（自动完成）
git add -A

# 3. 创建标签（自动完成）
git tag v1.6.0

# 4. 推送到远程
git push origin v1.6.0
```
