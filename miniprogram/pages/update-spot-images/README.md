# 手动修改景点图片URL使用指南

## 功能概述
此页面提供了手动修改景点图片URL的功能，支持三种操作模式：

1. **直接更新图片URL** - 直接替换景点的所有图片URL
2. **替换现有图片** - 删除所有旧图片，添加新图片URL
3. **添加新图片** - 在现有图片基础上添加新图片

## 使用步骤

### 1. 获取景点ID
首先需要知道要修改的景点ID，可以通过以下方式获取：
- 在景点详情页面查看
- 在景点列表中查看
- 通过数据库查询获取

### 2. 准备图片URL
图片URL必须是有效的微信云存储fileID格式，例如：
```
cloud://env-id.746f-app-name/spots/spot_123/image1.jpg
```

### 3. 选择操作方式

#### 方式一：直接更新
- 输入景点ID
- 输入新的图片URL（每行一个）
- 点击"直接更新图片URL"
- 系统会直接替换景点的images字段

#### 方式二：替换现有图片
- 输入景点ID
- 输入新的图片URL
- 点击"替换现有图片"
- 系统会先删除所有现有图片，然后设置新图片URL

#### 方式三：添加新图片
- 输入景点ID
- 输入要添加的图片URL
- 点击"添加新图片"
- 系统会在现有图片基础上追加新图片

## 注意事项

### ⚠️ 重要提醒
1. **图片URL格式**：必须使用有效的云存储fileID，不能使用HTTP URL
2. **权限验证**：确保有修改景点的权限
3. **数据备份**：修改前建议备份原有图片URL
4. **网络环境**：确保网络连接正常

### 🔧 技术说明
- 图片URL存储在景点的`images`字段中
- 支持最多9张图片
- 图片按数组顺序显示

## 故障排除

### 常见问题
1. **更新失败**：检查景点ID是否正确，图片URL格式是否有效
2. **权限错误**：确认用户是否有修改权限
3. **网络错误**：检查网络连接，重试操作
